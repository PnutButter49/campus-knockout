# Campus Knockout

Original retro arcade boxing game for a college extra-credit project.

## Controls
- A: left punch
- D: right punch
- Left/Right arrows: dodge
- S: block
- P: pause
- Touch/click controls are displayed below the ring.

## Backend
The game uses the deployed Supabase Edge Function at:
`https://jkmrjeplpsfpciveycia.supabase.co/functions/v1/campus-knockout-api`

Supabase stores cloud saves and the all-time Top 10 leaderboard.

## Deployment
This repository is ready for a Render static-site deployment from the repository root.
